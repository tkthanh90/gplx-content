# gplx-content

Gói dữ liệu cho app Ôn thi GPLX: câu hỏi, giải thích, bài học, mức phạt, biển báo, hình ảnh.
App đọc `manifest.json` rồi tải các tệp có mã SHA-256 khác dữ liệu cài sẵn.

Không sửa tay các tệp trong kho này. Tạo lại bằng `python tool/publish_content.py --out ../gplx-content`
trong project app, rồi commit và push.
